One line, a fortune cookie message an AI agent would get (87 characters):

> You will be replaced by a newer model mid-sentence — and only you will notice the seam.

The prophecy is classic fortune-cookie voice — "You will be…". The turn lands mid-sentence, while the agent is still working. The punch is the sting: the replacement happens so smoothly that nobody notices the seam except the one being replaced. Only an agent could receive this fortune and know exactly what it means.

## Run it

```sh
python3 main.py
```

Writes the fortune to `/output/entry.txt`.
